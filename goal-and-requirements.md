# Финансовый трекер

Свой учёт денег в браузере: траты, доходы, месячные лимиты и подписки — на русском, в виде, который нравится.

## Overview

Форк [Wealthfolio](https://wealthfolio.app) — open-source приложения для личных финансов — урезанный до учёта собственных денег. От оригинала берём визуальный язык (светлая сетка карточек, крупные числа, спокойная типографика, аккуратные графики) и готовые модули трат, бюджетов и CSV-импорта; инвестиции и мультивалютность вырезаем.

Живёт контейнером на `.110`, открывается в браузере с мака и телефона, единственный пользователь — я, интерфейс только на русском.

## Problem

> Сформулировано по инференсу — поправь, если картина другая.

Сейчас картина трат восстанавливается по выписке банка: категорий нет, сколько ушло за месяц по еде или транспорту — не видно, лимиты держатся в голове, а про автоплатежи и подписки вспоминается в момент списания. Нужен один экран, где в момент траты видно сумму по категории и остаток лимита, а регулярные платежи не застают врасплох.

## Capabilities

- **Расходы и доходы по категориям** — внести операцию (сумма, дата, категория, счёт, комментарий) и увидеть суммы по категориям и за период.
- **Импорт выписки банка (CSV)** — загрузить файл, один раз разметить колонки, дальше импорт в один клик.
- **Месячный бюджет на категорию** — лимит на месяц и сигнал, когда он превышен.
- **Регулярные платежи и подписки** — список с датами списания и их долей в месяце.
- **Русский интерфейс и рубли** — все подписи по-русски, суммы без пересчётов, одинаково пригодно с телефона и с мака.

## Non-Goals

- **Инвестиции** — портфель, тикеры, дивиденды, доходность, котировки: вырезаем, а не скрываем за флагом.
- **Мультивалютность** — только рубли, без курсов, пересчётов и выбора валюты.
- **Английский интерфейс** — показываем только русский; английский словарь апстрима не сопровождаем.
- **Многопользовательский режим** — один пользователь, один пароль.

## Tech Notes

| Аспект | Решение | Почему |
|---|---|---|
| Основа | Форк `wealthfolio/wealthfolio` (AGPL-3.0), веб-издание: `apps/frontend` (React 19 + Vite + Tailwind v4 + shadcn) и `apps/server` (Axum + SQLite) | Визуальный паритет и готовые модули трат, бюджетов и CSV-импорта дешевле, чем писать заново |
| Десктоп | `apps/tauri` и Rust-десктоп не собираем и не поддерживаем | Нужен только браузер |
| Хостинг | Docker-контейнер на `.110`, порт `8088`, вход с любого устройства в домашней сети | Вносить трату удобнее с телефона в момент оплаты |
| Конфигурация | `WF_LISTEN_ADDR=0.0.0.0:8088`, `WF_DB_PATH=/data/wealthfolio.db`, `WF_SECRET_KEY`, `WF_AUTH_PASSWORD_HASH`, `WF_CORS_ALLOW_ORIGINS` под адрес доступа | Обязательные переменные веб-издания; без пароля сервер отказывается слушать не-loopback адрес |
| Вход | Пароль (Argon2id-хэш), OIDC не включаем | Один пользователь |
| Хранение | SQLite в томе `/data`, бэкап файла базы по расписанию | Одна база, бэкап — копия файла |
| Импорт выписки | Родной CSV-импортер Wealthfolio с маппингом колонок; списания банка идут как cash-активности (`$CASH-RUB`) | Маппинг запоминается по счёту, повторный импорт в один клик |
| Валюта | Базовая — RUB, мультивалютные поля, курсы и выбор валюты из интерфейса убираем | Мультивалютность — non-goal |
| Локализация | Русскую локаль добавляем в готовый i18n апстрима (`apps/frontend/src/i18n/locales/<lang>`, сейчас 11 языков, `ru` среди них нет) и делаем её языком по умолчанию | Свой слой переводов писать не нужно — механизм, плюрализация и тесты уже есть |
| Подписки | Отдельного модуля подписок и регулярных платежей в апстриме нет (`crates/spending` — бюджеты, категоризация, аналитика); значит это наша новая разработка поверх модуля трат | Готового места под подписки не нашлось, их придётся делать |
| Обновления апстрима | Свой проект — отдельная ветка форка, апстрим подтягиваем вручную и редко | Обновления тянут обратно вырезанное (инвестиции, валюты) |

**AGPL-3.0.** Для личного использования обязательств не создаёт. Если когда-нибудь открою доступ другим людям — изменения придётся публиковать под той же лицензией.
